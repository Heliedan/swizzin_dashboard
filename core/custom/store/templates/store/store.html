App Store

The applications Swizzin can install. Installing one runs box install <name> on the server, as root, exactly like over SSH: it can take a few minutes, and some installers ask questions in the terminal. System components and tools set up on the machine itself (nginx, Let's Encrypt, WireGuard, rclone…) are not offered here: install them over SSH. Some installed apps can also be uninstalled from here: a copy of their settings is saved first.
